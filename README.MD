# 🌸 Personal Portfolio Website

This is my personal portfolio website built using HTML and CSS.  
It highlights who I am, the projects I’ve worked on, and the technologies I’m continuously learning and exploring.

The design focuses on clean structure, responsive layout, smooth animations, and subtle visual personality.

---

## 🚀 Features

- Responsive, mobile-first layout  
- Animated gradient text effects  
- Slide-up entrance animations  
- Smooth scrolling  
- Reduced motion support (`prefers-reduced-motion`)  
- System-based dark mode (`prefers-color-scheme`)  
- Flexible image grid with hover effects  
- Custom lightbox gallery  

---

## 🛠️ Built With

- HTML5  
- CSS3 (Flexbox, media queries, animations)
